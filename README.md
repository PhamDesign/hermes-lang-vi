# Hermes Vietnamese Language Pack

Vietnamese (Tiếng Việt) language pack for Hermes Desktop.

*Vietnamese translation by [openai.vn](https://openai.vn)*

## Installation

### Option 1: Install as plugin
```bash
hermes plugins install hermes-lang-vi
```

### Option 2: Manual install (user overlay)
Copy `locales/vi.desktop.yaml` to your Hermes home:
- Linux/macOS: `~/.hermes/locales/vi.desktop.yaml`
- Windows: `%LOCALAPPDATA%\hermes\locales\vi.desktop.yaml`

Then restart Hermes Desktop and select **Tiếng Việt** in Settings → Language.

## Details
- **5,206 strings** translated (99.6% coverage of the official desktop key list)
- Partial translations are fine — missing keys fall back to English
- Survives Hermes updates (user overlay, no build patching)
